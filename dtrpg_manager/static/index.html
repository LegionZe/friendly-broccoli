Automatic tagging

Run the passes in order. Pass 1 applies DriveThruRPG's own categories directly. Passes 2 and 4 only suggest tags, which wait in the review queue below. Tags you add yourself are never changed, and anything you remove or reject is not suggested again.

1 · DriveThruRPG categories

Genre → genre tags, Rule System → system tags, Product Type → type. Free and reliable.


        
2 · Keyword rules

          
Patterns over title, description and PDF text (e.g. “5e”, “solo”, “2–6 players”). Edit them below.

           

        
3 · Read downloaded PDFs

          
Page count, PDF metadata and the first pages' text, used by passes 2 and 4. Runs locally.

           

        
4 · AI suggestions (Claude Haiku 5.5)

          
Paid. Uses the Message Batches API (half price, usually done within an hour). Needs an Anthropic API key in Settings.

Local books

      
Folders with game books bought elsewhere or scanned (PDF, EPUB, CBZ/CBR, MOBI/AZW3, DjVu). Subfolders are included; files are only read, never moved or changed. One folder per line, e.g. /home/you/RPG PDFs.

      
      

      
Downloads on hold

      
Files whose download failed a check (checksum in strict mode, or not a PDF) are skipped by “Download all” for
         hours (0 = never hold). Downloading a single file from its product panel ignores the hold.
